Settings

Team, pipeline statuses, filter lists and duplicate rules.

Team
Who leads can be assigned to. Renaming someone moves their leads with them; removing someone sends their leads back to Unassigned.
Click a colour square to change it.
Pipeline statuses
Each status is a column on the board. The short name is the column header, the full name shows in dropdowns. Toggle Call to count a move into that status as a call attempt.
Rejected is the duplicate bin and can't be renamed, moved or removed. Removing a status moves its leads to the first column.
Filter lists
The options behind the filter dropdowns. Renaming an option updates every lead using it. An option in use can't be deleted.
Duplicate rules
These decide what gets rejected on the way in. Changes apply immediately.

Signals compared

Phone
Last 10 digits only, country code ignored
Email
Lowercased, plus-tags and dots stripped on Gmail
Clinic
Punctuation and Clinic / Dental / Care / Centre removed
Doctor
Dr / Prof titles and punctuation stripped
Address
Street-type words, unit numbers and country removed
Website
Protocol, www and trailing slash removed
Dev mode
Destructive tools the team should never reach, plus edit access to everything else in Settings. Unlocks on a timer, then locks itself.
Calling and WhatsApp
A number stored as 098200 11223 has no country code, so a WhatsApp link built from it goes nowhere. This gets prefixed. Numbers already starting with + are left alone.
